# Luxora Games

This project is a simple static landing page for Luxora Games. It showcases the studio's brand, upcoming games, contact information, and social links.

## Project Structure

- index.html: Main HTML structure for the website sections such as Home, About, Games, Contact, and Footer.
- style.css: All visual styling, layout, colors, animations, and responsive design rules.
- script.js: Interactive behavior such as the image carousel, smooth scrolling, hover effects, and animations.
- static/: Directory for images and other media used by the page.
  - static/icones/: Social media icons.

## How to View Locally

1. Open the project folder in your browser.
2. Double-click index.html, or use a simple local server such as Live Server in VS Code.

## Notes

- This website is fully front-end based and does not require a build step.
- Keep the folder structure intact so that images and assets continue to load correctly.
